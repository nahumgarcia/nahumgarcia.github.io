# Blog de Nahúm García

> Este blog comenzó como un fork de TextLog pero ha cambiado tanto que los parecidos son ya casi una casualidad. Consiste en un blog bastante estándar, con más hincapié en las imágenes para que sea más visual, y aparte un feed de fotos, y unas galerías a las que pueden pertenecer esas fotos.
